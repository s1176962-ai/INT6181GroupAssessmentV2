# 2026-11-11

## 全项目代码 / 架构梳理（为前端美化做准备，未改业务代码）

- 关键结论：本项目是 **Tkinter 单窗口离线桌面应用**，不是 Web 项目；无 HTML/CSS/JS、无模板引擎、无路由。所谓「前端」= `learning_platform/gui.py`（4242 行单类 `Application`，含 `_style()` 集中 ttk 样式表 + 全部页面方法）+ `ui_tokens.py` + `widgets.py` + `editor_ui.py` / `user_ui.py` + `assets/*.png`。
- 启动链：`start.bat` → `launcher.py`（检查 Python/Tk/题库 → 建 Tk 根窗口）→ `Application(root)` → `login_page()`。等价入口 `main.py` / `python -m learning_platform`。
- 页面切换无路由：导航回调 → `clear()` 销毁 `body` 子控件 → 页面方法重建；主题切换走 `apply_theme()` → `_rebuild_screen()`。
- 样式三层：`ui_tokens.py`（唯一配色真源，双主题 `set_theme()` 运行时 globals 重绑）→ `gui.py:_style()` 258-575（约 318 行 ttk 具名样式）→ 页面内 139 处内联 `font=(FONT,n)` / 逐控件 `bg`、`fg`。颜色必须渲染时读 `T.<TOKEN>`（DESIGN.md:122-123）。
- 页面清单：login_page 1023、home 2149、settings 1419、configure 3174、show_question 3693、results 3919、notebook 4034、history 4168、personal_bank_page 2832、每日目标弹窗 2538；`editor_ui.py` / `user_ui.py` 为表格表单。
- 硬约束：`tests/test_gui.py` 等 84 项测试直接断言控件属性 / pack 层级，改名或换控件类型会挂；必须用项目解释器 `py -3 -m unittest discover -s tests`；新增文案要补 `locales/en.json`（中文为键）；图片仅 PNG/GIF/PPM/PGM；约 500 行 legacy 死代码（_legacy_home / _legacy_personal_bank_page / _plan_ring / _weekly_chart）勿误改。
- 视觉遗留：题图 / 学科图 / PDF 仍是浅米白底，与深色主题割裂。当前视觉基线截图在 `.workbuddy-ai/preview/{home,login}-{dark,light}.png`。
- **用户历史约定（见 `.workbuddy-ai/memory/2026-11-10.md:32`）：不要主动改首页；首页美化须单独等用户明确指令。** 本轮仅梳理，未动任何代码，下一步需先确认美化范围与风格。

## v2.4 最大化窗口 / 高 DPI 显示修复（用户三张截图驱动）

- 用户反馈三张图：① 设置页单选项只剩圆点、说明文字挤窄列、登录页工具栏 "gh n" 裁切；② 打开不是最大化，首页四卡下方大片空白；③ 登录页局促要「大气」；④ 默认初始语言要英语。
- **关键坑（务必记住）**：`_strip_focus()` 不能删除整个 `.focus` 节点。clam 主题把 `Radiobutton.label` / `Checkbutton.label` 嵌在 `Radiobutton.focus` 里，删整节点 → 所有单选/复选只剩圆点。正确做法是「提升子节点到父级后再删焦点节点」。TButton 的 `.focus` 里是 `padding` → `label`，同理。
- **第二坑**：Tk 所有 `wraplength` 写死常量在 125/150% DPI 或最大化窗口下必然裁切/窄列。统一改为 `<Configure>` 回调按 `event.width` 动态设置（`label()`、设置页 `fit()`、配置页 `column()`、首页空状态）。首页空状态曾用 `T.px(460)` 导致 100% 窗口截尾，已改自适应。
- `gui.py:maximize_startup()`：Windows `state("zoomed")` → X11 `-zoomed` → 兜底 screen-80 几何；`launcher.py` deiconify 后调用、`gui.main()` 内调用。
- 滚动画布 body 窗口按视口高度拉伸（`itemconfigure(window, height=...)` + `coords`），首页 grid 两行 `weight=1` 才能铺满；首页卡片内距统一 `pad=T.SPACE_5`(24)、内部 padding 全部过 `T.px()`；空状态垂直居中。
- 登录页：`CARD_WIDTH` 420→520、`TYPE_HERO` 标题、`login_form` 加宽且工具栏独立成行不再被表单宽度挤压，表单改 `card_frame(pad=T.SPACE_6)` 圆角柔和阴影。`_layout_login()` 的 `needed` 用 `winfo_reqwidth()` 防裁切。
- 设置页：`LabelFrame` padding 统一 `T.SPACE_5`、说明文字 `fit()` 铺满卡片宽度；深色/语言/动画单选项文字恢复。
- 默认语言本来就是 `en`（`Translator` 默认 `{"language":"en"}` 且 `data/settings.json` 为 en），新增 `LanguageTests.test_new_profile_starts_in_english` 锁定，测试数 84 → **85**。
- 新增验收脚本 `.workbuddy-ai/capture_fullscreen.py`（临时 profile + 最大化 + 125/150% 截图）；截图 `full-dark-{login,home,settings}-{125,150}.png` 与 `detail-*.png`。
- 文档：`DESIGN.md` v2.4、`README.md`、`docs/CHANGELOG.md` 同步。验证：py_compile OK、85 项全通过、三张问题图逐项复验通过。

## v2.5 答题页 Ask AI 上下结构 / 英文纯净 / 列表撑满（用户四张截图驱动）

- 用户反馈：① 答题页 Ask AI 要改成「上下结构」（附红框手绘结构图：标题 → 回复区 → 头像 + 宽按钮，且整块要撑满列高）；② 英文模式 AI 回复仍是中文，要求切换英文后无中文；③ 配置页难度标签 `全部/简单/中等/困难` 与摘要里的「全部」要英文；④ 题库管理表格下方大片空白，要撑大。
- **Ask AI 重构**：`show_question()` 改 `split.columnconfigure(0/1, weight=1)` + `split.rowconfigure(0, weight=1)`（关键：原来没有加权行，所以右列永远是短卡片）；新增 `_quiz_ai_panel(split)` 用 `card_frame(pad=T.SPACE_5)` 做 grid 三行：head（标题 + 「每题可询问一次」）→ 加权行 1 的全宽 `AssistantReply` 气泡 → footer（圆形头像 + `modern.SoftButton` 宽按钮）。`_circle_avatar()` 用 Canvas oval + subsample 后的 `AI-assistant-icon.png`。删除旧的 `Idea.TButton` 块与 `quiz_ai_reply.character` 依赖；测试只断言 `quiz_ai_button.winfo_exists()`，已保留。
