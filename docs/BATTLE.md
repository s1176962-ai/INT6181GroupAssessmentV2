# 答题对战

双方初始 100 HP，每题低分方扣除双方总分差值，最低为 0；归零后点击继续进入结算，题目用尽时按剩余血量判胜负。配置 API Key 后，揭晓答案时额外请求一次教育复盘，包含选项比较、可能误区与学习建议；失败时保留题库解析。该请求沿用 320 tokens 上限。复盘不展示模型内部思维链，错误原因作为可能解释呈现。

侧边栏向访客、学生和管理员开放。使用公共题库，支持科目、题量与四档对手选择。

每题双方同时开始，限时 30 秒。正确分为 100；正确作答且用时不超过 5、10、15、20、30 秒时，时间分分别为 50、40、30、20、10。错误或超时没有正确分与时间分。额外分单独保留，默认 0。总分相同为平局。

设置中选择 Local 使用本地模拟，选择 API 则复用现有 AI 设置与客户端。`LocalOpponent.answer(question, level)` 和 `ApiOpponent.answer(question, level)` 共用返回契约 `(选项文本, 思考秒数)`，可替换为其他提供者。

API 在后台线程请求，只发送题干和文字选项，附带等级控制词，校验返回的选项索引和时间范围；网络实际耗时也计入作答时间，30 秒未返回按未作答处理。API 的准确率为提示词目标，不能保证严格达到统计概率。Local 模式则由程序控制：入门级准确率 50%，延迟 12–24 秒；普通级 72%，8–18 秒；困难 88%，4–12 秒；地狱 97%，2–7 秒。概率是长期目标，不保证单轮比例。错误时更偏向选择与答案文字相似的干扰项。双方锁定后统一揭晓结果。

对手角色设定：你是参与学习对战的真人风格玩家，依照所选等级表现出思考、犹豫与失误；不要提前揭示答案。未来接入语言模型时仍由本地规则限制等待时间与概率。

头像使用根目录 AI-assistant-icon.png。当前以文字显示思考/锁定状态，尚未生成额外表情素材。对战结果独立于普通练习成绩、每日目标与错题本，当前仅在本轮会话内展示。
# 决策与讲解分离 · 2026-11-13

API 模式将当前题目 ID、题干和选项发送给模型，不发送标准答案、题库解析或图片。模型一次返回结构化决策：题目 ID、选项索引、模拟耗时及简短选择依据。程序校验题目绑定、索引范围、有限耗时和依据包含所选项，保存不可变 OpponentDecision，结算后展示同一份依据及独立的题库解析。结算不再额外调用生成式讲解接口，也不把随机选择描述成模型解题。显示内容是模型提交的决策摘要，不代表内部推理轨迹；结构校验不能保证语义正确。

Local 保留原等级概率模拟，并明确标识其不是真实模型解题。已配置密钥时默认选择 API。API 等级控制检查要求及模拟等待范围，不再要求模型按正确率随机答错；因此实际正确率不保证达到固定比例。等待秒数属于游戏模拟参数，不是 API 推理实测耗时。接口失败按未作答处理，不偷偷回退随机答案。

# 三阶段动态展示

2026-11-13：作答时使用“读题 → 分析选项 → 选择并检查”的替换式活动提示，上一段不累积。该进度是按等级等待时长播放的界面表现，不代表模型内部处理进度。选项判断与答案继续保密，双方结束后展示 API 随同选择提交的三段简短教育摘要及题库解析，不再保留提交状态文案。API 未返回摘要时使用已保存的简短选择依据，不伪造分析。

# 对战图片输入 · 2026-11-13

API 对战现在将题干图片及选项图片作为带标记的 Base64 内容块发送，保留题目 ID、题干及选项；不发送答案键或题库解析。仅接收项目目录内实际存在的图片，按文件内容识别 PNG/JPEG/GIF/WebP，单图上限 8 MiB、总计 16 MiB。无法读取或格式不支持时本题不作答，不静默丢弃图片后猜答案。

官方 DeepSeek 地址的图片请求使用 `deepseek-flash`，纯文本请求仍使用设置中的模型，不更改保存的设置。自定义兼容接口沿用配置模型，使用者需选择支持图像输入的模型。Local 仍是概率模拟，不具备视觉理解。玩家侧同步展示选项图。

协议参考：https://api-docs.deepseek.com/guides/vision/ 。自动测试使用模拟网络响应，尚未以真实密钥验证识图质量。

# 接口异常处理

提交前修复：接收响应时首先检查 30 秒截止时间，迟到响应不会进入选择及扣血分支。2026-11-13 已使用本机配置进行一次真实视觉接口联调，MAT009 返回选项 5 与三段摘要；该结果仅覆盖单题联通与解析，不代表所有图题均能正确识别。

2026-11-13：接口错误、结构校验失败或未得到决策的请求超时均使当前轮次作废；不累计成绩、不计算血量差，不展示伪造答案。保留双方血量和前轮记录，显示错误原因，提供“重试本题”。结构化作答采用独立系统约束和 JSON 输出模式，输出上限为 800 token；普通伴学维持 320 token。输出被截断时报告错误，不尝试从残缺 JSON 猜测选项。真实服务错误需根据页面显示的原因排查，模拟网络测试不等同于真实接口验证。
